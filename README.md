# Noor Quran Academy — Next.js Portal

Full Quran Academy portal rebuilt in **Next.js 14 (App Router) + TypeScript + Tailwind CSS**.
Name is a placeholder — change it in one place: `src/config/site.ts` (`SITE.name`).

## What is inside

- **Public site (English main, Roman Urdu toggle):** Home, Courses (Noorani Qaida, Nazra, Hifz, Tajweed, Tafseer — each with its own page), Teachers, Fees, Timetable, Admission / Free Trial form, FAQ, Contact, Free Trial landing page, and country landing pages for UK / USA / Canada / Australia (`/countries/uk`, `/countries/usa`, `/countries/canada`, `/countries/australia`).
- **Fees:** $30/£25 per month (3 classes/week), $50/£40 per month (5 classes/week). PKR fees are blank on purpose — the page shows “WhatsApp par poochein”.
- **Payments — bank only:** Wise to bank account, Remitly to bank account, Western Union, direct bank transfer (SWIFT/IBAN), plus JazzCash/EasyPaisa for Pakistan only. **No PayPal, no Stripe, no Payoneer anywhere as a payment method.** The academy only has a bank account and does not need a Wise/Payoneer account — the student sends from their own Wise/Remitly app to the academy’s IBAN. Payment proof is a screenshot / transaction ID on WhatsApp; the teacher confirms it in the dashboard.
- **WhatsApp everywhere:** 03127675565, international +92 312 7675565, link `https://wa.me/923127675565`.
- **Student login (by phone):** dashboard with attendance, homework, fees, teacher name, class time, and a 30-para Hifz Tracker. Demo phone: `03127675565`.
- **Teacher:** “Teach With Us” apply form (goes to the owner for approval), teacher login, teacher dashboard showing only their assigned students, homework/class-time editing, and marking fees Paid.
- **Owner/Admin Dashboard:** all students, teachers, fees, student-to-teacher assignment, teacher approvals, and teacher pay tracking (monthly salary or commission % of fees collected, with due / given / balance). Demo PIN: `1234` — **change it before going live** (see below).
- **Timing is flexible, not fixed:** “Flexible Timing — You Choose Your Class Time”. The student chooses the time; owner/teacher can change each student’s class time in the dashboards. Timezone selector for UK/USA/Canada/Australia; shown times are examples only.
- **AI tools (`/ai-tools`):** AI Quran Assistant (answers in Roman Urdu/English about fees, bank payment, timing, trial, Hifz — never offers PayPal), AI Quiz for Tajweed/Qaida, AI Hifz Revision Planner (7-day plan from memorised paras). Rule-based helpers, no external AI account needed.
- **SEO + GEO from the start:** Next.js metadata (title, description, keywords, Open Graph), JSON-LD for Organization, Courses and FAQ, `sitemap.xml` and `robots.txt` (generated by `src/app/sitemap.ts` / `robots.ts`), semantic headings, plain factual FAQ answers for AI search. There is **no** visible “Built for Google, AI Search & Smart Learning — SEO · GEO · AI” section — SEO/GEO/AI work in the background.
- **Marketing:** Phase 1 is SEO only. No paid ads are running; only the Free Trial landing page is ready.

## Deploy to Vercel

1. Push this folder to GitHub (or import it directly in Vercel).
2. In Vercel: **Add New → Project → Import** the repo, framework preset **Next.js**. No environment variables are needed.
3. Deploy. Set your real domain in Vercel → Settings → Domains, and update `baseUrl` in `src/config/site.ts` to that domain, then redeploy.
4. No database is needed — data is stored in the browser (localStorage, see below).

- Owner Dashboard → Bank Settings: **bank name, account title, IBAN, SWIFT code** — students send money to this account. Never share these in chat.
- Real teachers: approve real applications from the Owner Dashboard; delete the demo teacher profiles.
- Real parent reviews: replace the two demo reviews on the home page.
- Owner PIN: the demo PIN `1234` in `src/components/Dashboards.tsx` (`OwnerDashboard`) must be replaced with a real password/login before going live — this demo has no real auth.
- PKR fees: set them in `src/config/site.ts` (`plans[].pkr`) when you decide them; while `null`, the site shows “WhatsApp par poochein”.
